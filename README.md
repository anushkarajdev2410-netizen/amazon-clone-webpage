# amazon-clone-webpage
Amazon website clone built with HTML and CSS for frontend development practice.

Amazon Website Clone

A frontend Amazon website clone created using HTML and CSS, as a web development mini project. The project recreates the look and feel of an Amazon-style e-commerce homepage with a navigation bar, search section, promotional banner, and product categories.

«Note: This project is created for educational and frontend development practice. It is not affiliated with or endorsed by Amazon.»

---

📌 Project Overview

The Amazon Website Clone is a static frontend project designed to practice and demonstrate fundamental web development concepts.

The website is inspired by the layout and visual structure of an e-commerce platform and includes sections such as navigation, search, promotional content, and product categories.

The main goal of this project is to understand how HTML, CSS can be used together to create an attractive and user-friendly website interface.

🚀 How to Run the Project

Method 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Locate "index.html".
4. Double-click "index.html".
5. The website will open in your web browser.

Method 2 — Using VS Code

1. Open the project folder in Visual Studio Code.
2. Open "index.html".
3. Install the Live Server extension if required.
4. Right-click "index.html".
5. Select Open with Live Server.

The website will then open in your browser.
